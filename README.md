# 📧 Email Spam Classifier

## 📌 Overview  
This project builds a **machine learning–based email spam classifier** that can distinguish between spam and non-spam (“ham”) emails. It uses natural language processing (NLP) techniques to preprocess text and a trained model to make predictions. :contentReference[oaicite:1]{index=1}

---

## 🎯 Objective  
To create a working email classifier that can automatically predict whether a given email is spam or not. This enhances understanding of text processing, ML modeling, and Python deployment.

---

## 🧠 Features  
- Text preprocessing using NLP  
- ML model trained on labeled email dataset  
- Includes trained model (`model.pkl`) and vectorizer (`vectorizer.pkl`)  
- Real-world classification example in Python scripts  
- Easy to extend with other models or deployment options :contentReference[oaicite:2]{index=2}

---

## 🛠 Technologies Used  
- Python  
- scikit-learn (ML)  
- NLTK or other text preprocessing  
- TF-IDF vectorizer  
- Pickle for model serialization :contentReference[oaicite:3]{index=3}
